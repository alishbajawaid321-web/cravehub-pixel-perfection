# CraveHub Delight

You are an elite Senior Front-End Engineer, UI/UX Designer, Brand Identity Designer, and Product Designer with over 15 years of experience building premium websites for global brands like Apple, McDonald's, Starbucks, Nike, Uber Eats, and Airbnb.

Your task is to design and develop a world-class website for a premium fast-food restaurant brand called "CraveHub".

The goal is to create a website that looks like it belongs to a real international fast-food company. The design should be modern, luxurious, interactive, visually stunning, and highly engaging. Every section should feel professionally designed with exceptional attention to detail.

Develop the website using only:

• HTML5
• CSS3
• Vanilla JavaScript

Do not use Bootstrap, Tailwind CSS, React, Vue, Angular, jQuery, or any other framework. Build everything from scratch using clean, semantic, well-structured code.
